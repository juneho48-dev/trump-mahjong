# 트럼프 마작 · P2P 온라인 버전

## GitHub Pages 업데이트

1. ZIP을 압축 해제합니다.
2. 기존 `juneho48-dev/trump-mahjong` 저장소의 Code 화면에서 **Add file → Upload files**를 누릅니다.
3. 압축을 푼 **폴더 안의 파일과 폴더 전체**를 올립니다. ZIP이나 바깥 폴더 자체를 올리지 마세요. `index.html`이 저장소 첫 화면에서 보여야 합니다.
4. 기존 동명 파일을 새 파일로 덮어쓰고 **Commit changes**를 누릅니다.
5. Actions의 Pages 배포가 완료되면 사이트를 새로고침합니다. 예전 화면이면 Windows는 Ctrl+Shift+R, Mac은 Command+Shift+R을 누릅니다.

`cards/`, `vendor/`, `p2p-session.js`, `multiplayer.js`도 반드시 함께 올리세요. 기존 Pages 설정은 바꿀 필요가 없습니다.

## 친구와 플레이하기

1. 한 사람이 사이트에서 **온라인 대전 → 방 만들기**를 누릅니다.
2. **초대 링크 복사**를 눌러 친구에게 보내거나 10자리 방 코드를 전달합니다.
3. 친구는 링크를 열고 **참가하기**를 누릅니다. 또는 같은 사이트의 온라인 대전에서 방 코드를 입력합니다.
4. 대기실에 참가자가 모두 **연결됨**으로 나타난 뒤 방장이 **게임 시작**을 누릅니다.
5. 최대 4명이 참가합니다. 빈자리는 AI가 맡고, 모든 플레이어는 자기 자리가 화면 아래에 보입니다.

계정 생성, 별도 서버 설치, API 키, 포트 포워딩은 필요하지 않습니다. 원래의 1인 대 AI 모드도 남아 있습니다.

## 온라인 진행

- 방장이 카드 분배, 화료 판정, 점수 정산을 담당합니다. 참가자에게는 자기 손패와 공개 정보만 전송합니다.
- 론은 모든 해당 플레이어가 응답할 때까지 모아 동시 론을 처리합니다.
- 치·퐁·론 응답은 15초 후 자동으로 넘깁니다. 이미 수락한 론은 다른 사람의 시간 초과로 취소되지 않습니다.
- 치·퐁 우선순위는 원래 규칙을 따릅니다. 자기 차례의 버림패 선택에는 시간 제한이 없습니다.
- 중복 전송은 한 번만 처리하고, 지난 상태의 행동과 다른 사람의 카드 조작은 거부합니다.
- 참가자의 연결이 끊기면 게임을 멈춥니다. 같은 브라우저 탭에서 자동 재접속하며, 실패하면 방 정보에서 **재접속**을 누릅니다.
- 참가자 새로고침 후에도 같은 탭·방 코드로 참가하면 자리를 복구할 수 있습니다. 브라우저 세션 저장을 차단하거나 탭을 닫으면 복구가 어려울 수 있습니다.
- 돌아오지 않는 참가자는 방장이 **방 정보 → AI로 이어하기**로 교체할 수 있습니다. 교체된 참가자는 그 게임에 재참가할 수 없습니다.
- 게임 시작 후 새로운 참가자는 들어올 수 없습니다. 기존 참가자의 재접속만 가능합니다.
- 방장만 다음 세트 또는 새 게임을 시작할 수 있습니다.

## 연결 방식과 한계

PeerJS 1.5.5 클라이언트를 `vendor/`에 포함했습니다(MIT 라이선스 동봉).
무료 PeerJS Cloud가 WebRTC 연결을 위한 신호 교환을 담당합니다. 연결 이후 게임 데이터는 방장과 참가자의 브라우저 사이에서 전송됩니다. 별도 게임 서버나 TURN 중계 서버는 설정하지 않았습니다.

- 인터넷 연결과 HTTPS가 필요합니다. GitHub Pages에서 실행하세요. `index.html`을 파일로 더블클릭해 여는 방식은 지원하지 않습니다.
- 무료 공용 신호 서비스의 가용성은 보장되지 않습니다.
- 일부 공유기, 대칭 NAT, 회사·학교망, VPN에서는 P2P 직접 연결이 안 될 수 있습니다. 이 경우 다른 네트워크나 휴대폰 핫스팟으로 시도하세요. 해당 환경까지 보장하려면 TURN 중계 서비스가 추가로 필요합니다.
- 방장의 탭을 계속 열어 두세요. 방장이 새로고침하거나 나가면 게임을 복구할 수 없습니다. 방장 이관과 서버 저장은 구현하지 않았습니다.
- 방장은 판정을 위해 모든 패를 관리합니다. 친구끼리 신뢰하고 플레이하는 구조이며, 방장의 개발자 도구 접근까지 막는 공정성 검증 시스템은 아닙니다.
- 방 코드를 아는 사람이 입장할 수 있습니다. 친구에게만 공유하세요.

공식 문서: https://peerjs.com/client/faq

## 포함된 화면 개선

- 커진 버림패와 공개 몸통
- 방금 뽑은 카드 맨 오른쪽 표시
- 손패 드래그 정리와 순서 유지
- 공개 몸통까지 확인하는 치·퐁 이후 화료 조건 검사

## 검증

자동 검사 8개를 통과했습니다. 4인 연결 모의 검사, 손패 비공개, 행동 권한 검사, 중복·이전 상태 전송, 동시 론, 시간 초과, 연결 중단 및 재접속, AI 교체, 100게임의 카드 108장 보존과 점수 합 0을 검사합니다.

실제 브라우저에서 무료 신호 서버 연결, 방 생성, 방장 화면의 패 분배·버리기·AI 진행을 확인했습니다. 테스트 환경에서는 브라우저 두 개 사이의 직접 데이터 연결이 성립하지 않아 실제 원격 대전의 전체 진행은 검증하지 못했습니다.

개발 검사는 Node.js 설치 후 압축을 푼 폴더에서 `npm test`로 실행할 수 있습니다. 별도 패키지 설치는 필요하지 않습니다.
